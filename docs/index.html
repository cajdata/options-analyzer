Strike Check GitHub

A read-only options scanner

Strike Check pulls option chains from Alpaca, ranks contracts by rules you can see, and puts each stock's past earnings moves next to what the options are pricing in for the next report. It runs on your own computer and it can't place orders.

What a scan gives you

A ranked list, with the rules in view

Each contract gets a score built from five parts: liquidity, breakeven or chance of profit, how volatility is priced, time decay or yield, and delta. Every weight and threshold is in one file you can read and change.

Earnings history next to the options' price

For each stock you get the next report date, the move on each of the last twelve reports, and the size of move the options price for the next one.

Risk and reward against the stock's own history

Chance of profit, average win and loss, expected value and the most you can lose. These assume you pay the ask to buy or receive the bid to sell, so a wide spread counts against a contract.

An exit plan

What the option is worth in one, two and three weeks if the stock stands still, the drop on the day an earnings report lands, and a seller's rules of thumb for closing early.

Recent news, sorted by type

Each stock's recent headlines and SEC filings, labeled by type of event, with how the stock moved after earlier events of the same type. The labels come from tables of keywords and filing codes, so read the headline before trusting one.

What it doesn't do

  • It can't place orders. It only reads market data and has no way to send an order.
  • It doesn't tell you what to trade. The ranking is a screen. It isn't a forecast and it isn't financial advice.
  • There's no hosted version. It runs on your own computer with your own free Alpaca keys.
  • Free quotes aren't live. Alpaca's free option feed is indicative: quotes are modified and trades are 15 minutes delayed. Screen with it, then check the live quote at your broker.

Try it without any keys

You need Python 3.11 or newer. Demo mode uses synthetic data, so it needs no account.

git clone https://github.com/cajdata/strike-check.git
cd strike-check
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev,ai]"
.venv\Scripts\python.exe -m app serve --demo

Then open http://127.0.0.1:8000. On macOS or Linux, use .venv/bin/python in place of .venv\Scripts\python.exe.

To use real data, the README covers the Alpaca keys and the earnings sources. It also lists the limits worth knowing before you rely on any number here.
